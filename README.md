# Amazon Diamond Hunter FREE

Бесплатный Telegram-бот для отслеживания **кандидатов** на скидки 50%+ на Amazon.fr (электроника, ПК, игровые товары).

**Важное ограничение:** без платного Keepa API бот не может подтвердить историю фактических цен за 30–90 дней. Он ищет заявления о скидках в публичном RSS Dealabs и отправляет их с пометкой **«НЕ ПОДТВЕРЖДЕНО»**, только когда обнаружена конкретная прямая ссылка `amazon.fr/dp/ASIN`. Не покупай товар, пока не проверишь текущую цену и продавца на Amazon.

## Запуск за 0 €

1. В Telegram открой [@BotFather](https://t.me/BotFather), отправь `/newbot`, выбери название и username. **Никому не присылай токен**, не вставляй его в код или чат.
2. Напиши новому боту `/start`.
3. Получи числовой chat ID через [@userinfobot](https://t.me/userinfobot).
4. В GitHub открой **Settings → Secrets and variables → Actions → New repository secret** и добавь:
   - `TELEGRAM_BOT_TOKEN` — секретный токен BotFather;
   - `TELEGRAM_CHAT_ID` — числовой Telegram ID.
5. На вкладке **Actions → Amazon Diamond Hunter FREE → Run workflow** запусти первую проверку. После настройки бот будет пытаться запускаться раз в 15 минут (GitHub иногда задерживает расписание).

## Возможности

- Бесплатный источник [Dealabs HOT RSS](https://www.dealabs.com/rss/hot.xml).
- Фильтр на технику/игровые товары и **заявленную** скидку от 50%.
- Только прямые ссылки на карточку товара Amazon.fr; если ASIN установить нельзя, сообщение не отправляется.
- Исключение явных б/у и восстановленных товаров по текстовым признакам.
- Уведомления на русском, защита от повторов с использованием GitHub Actions cache.
- Все секреты Telegram хранятся в GitHub Actions Secrets, не в публичном репозитории.

## Проверка

Локальные тесты без доступа к интернету: `python3 -m unittest discover -s tests -v`.

Тестовый поиск без сообщений в Telegram: `DRY_RUN=true python3 bot.py`. Для него нужен доступ к RSS.

## Ограничения

- RSS не даёт полный каталог Amazon, недоступные ссылки пропускаются; реальных уведомлений может быть мало или не быть вообще.
- История цен, наличие, продавец и итоговая цена Amazon.fr **не проверяются автоматически**. Перед покупкой нужно посмотреть актуальную карточку Amazon и график Keepa.
- Данные RSS могут устаревать; объявленный % — не доказанная скидка.
- GitHub Actions cron может задерживаться/пропускаться; расписание публичного репозитория может отключаться после 60 дней бездействия.
- Для бесплатного запуска используется публичный репозиторий и стандартный GitHub-hosted runner.
